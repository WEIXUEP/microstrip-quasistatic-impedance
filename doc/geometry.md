# 几何、材料与边界

## 坐标与单位

横截面使用 x–y 平面，传播方向垂直于截面。所有输入长度、几何属性和网格尺寸均以 **mil** 表示。Gmsh 在 mil 坐标中建模和导出网格；送入有限元前，节点坐标乘以 `25.4e-6` 转换为米。

![微带线横截面参数](microstrip_geometry.svg)

*不按比例绘制。地线的图示粗细仅用于辨识；计算模型没有地的厚度参数。*

| 对象 | 坐标或范围 | 材料 / 电位 |
| --- | --- | --- |
| 下层介质 | `−Ws/2 ≤ x ≤ Ws/2`，`0 ≤ y ≤ H1` | 相对介电常数 Er1 |
| 上层介质 | `−Ws/2 ≤ x ≤ Ws/2`，`H1 ≤ y ≤ H1+H2`，扣除信号线区域 | 相对介电常数 Er2 |
| 信号线底面 | `y = H1`，宽 W1 | 1 V |
| 信号线顶面 | `y = H1+T`，宽 W2 | 1 V |
| 信号线侧面 | 连接上下底面的直线 | 1 V |
| 有限宽地 | `y = 0`，`−Ws/2 ≤ x ≤ Ws/2` | 0 V |
| 空气区域 | 空气盒内除介质和金属以外的区域 | 相对介电常数 1 |

信号线底部放在两层介质界面上，厚度向上层介质内部延伸。H2 从界面量到上层介质顶面，**已经包含走线厚度 T**，所以走线上方的介质厚度为 `H2 − T`。

W1 与 W2 均为完整宽度，走线以 x=0 对称。W1=W2 为矩形；W1≠W2 为梯形，两种宽度关系都允许。

## 输入应满足的条件

- H1、H2、W1、W2、T 为正数，且 `T < H2`。
- 相对介电常数应是物理合理的正数；普通介质通常取 Er ≥ 1。
- 走线应位于基板内部，`max(W1, W2) < Ws`。
- 两个网格面积因子均大于零。

当前 CLI 只显式校验网格面积因子、T < H2 和阶数选择，其他条件需要使用者自行保证。负长度、零宽度或不合理材料可能在 Gmsh 或求解阶段报错。

## 基板与空气盒尺寸

令 `H = H1 + H2`，默认尺寸关系为：

```text
Ws = substrate_width_factor × H = 30H
空气盒半宽 = Ws/2 + air_padding_x_factor × H = 25H
空气盒底部 y = −air_padding_bottom_factor × H = −2H
空气盒顶部 y = H + air_padding_top_factor × H = 11H
空气盒总宽 = 50H
空气盒总高 = 13H
```

这些因子是 `MicrostripGeometry` 的 Python 字段，当前没有对应的 CLI 参数。调整方法见[计算域收敛](validation.md#domain-convergence)。

## 边界条件

信号线所有边界固定为 1 V，有限宽地固定为 0 V。地处于空气盒内部，其下方仍有空气，不是将空气盒底部全部接地。

空气盒外边界没有施加 Dirichlet 条件，因此有限元弱形式在这里采用自然边界：

```text
n · (ε ∇φ) = 0
```

即电位移法向通量为零。这是有限计算域的截断近似，应通过扩大空气盒检查影响。

介质界面由 Gmsh 碎分生成共形网格；连续的有限元电位和分区介电系数在弱形式中处理界面条件。金属内部不参与静电求解；实际导出的 `.msh` 仍保留金属区域的网格，详见[输出文件](output.md)。
